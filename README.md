# Comparative genomics of *Pilosibacter*

This repository contains the custom scripts and step-by-step protocols used for the comparative genomics analyses described in Bisenić et al. (2026), corresponding to §2.10 of the manuscript Methods.

## Analyses

* [KEGG module completeness](./KEGG_module_completeness/)
* [COG category enrichment](./COG_category_enrichment/)
* [GO term enrichment](./GO_term_enrichment/)

Each subdirectory contains the relevant scripts, a step-by-step protocol, and software version information.

## Reference genomes

Accessions for all genomes used in the comparative analyses (*Pilosibacter* genomes and the saccharolytic butyrate-producing reference genomes) are listed in **Supplementary Table 2** of Bisenić et al. (2026).
